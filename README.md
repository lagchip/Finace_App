# くらしの家計簿

ブラウザにデータを保存する家計簿Webアプリの試作です。収入・支出の登録、月別一覧、支出済み・予定額を確認できます。

## 開発環境

Node.jsとnpmを用意し、このフォルダで次を実行します。Windows PowerShellで `npm` が実行制限により使えない場合は `npm.cmd` を使用します。

```sh
npm install
npm run dev
```

ターミナルに表示されるローカルURLをブラウザで開きます。終了は `Ctrl+C`。ビルド確認は `npm run build` です。

データは使用したブラウザ内に保存され、別端末に自動同期されません。ブラウザのデータを消去すると記録も消える可能性があります。試作のため、大切なデータの保存には使用しないでください。

Excelの試作では、全期間の取引を月別シートに出力し、この試作が出力したファイルから新規取引を取り込めます。取り込み前に内容を表示し、同じIDで異なる内容があれば取り込みを中止します。既存取引の更新・削除、Excelでの新規行追加、予算・定期収支の受け渡しは未対応です。このファイルを完全なバックアップとして使用しないでください。

Excel処理のテストは `npm run test` で実行できます。ExcelJSの依存関係には修正方法を検討中の警告があるため、ライブラリの最終採用前に見直します。

予算、定期収支、編集・削除などは未実装です。[仕様書](kakeibo_spec.md)と[技術選定メモ](technology_selection.md)も参照してください。過去の `Kakeibo` と `Kakeibo.xcodeproj` はWeb化前のiOS試作です。
